# SpeedToon2d

SpeedToon2d is an open-source 2D animation application. It is a fork of [Tahoma2D](https://github.com/tahoma2d/tahoma2d), which is based on [OpenToonz](https://github.com/opentoonz/opentoonz).
The goal is a modern, Toon Boom Harmony-inspired workflow: a cleaner dark UI, a better workspace and docking, a horizontal timeline, layer hierarchy, a node editor, cut-out rigging and deformers. Existing Tahoma2D and OpenToonz scenes stay compatible.

**Status:** early development. See [docs/ROADMAP.md](docs/ROADMAP.md).

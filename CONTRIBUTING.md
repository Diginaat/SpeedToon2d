# Contributing

1. Read [AGENTS.md](AGENTS.md). Its rules apply to humans and AI agents alike.
2. Build using [docs/BUILD-WINDOWS.md](docs/BUILD-WINDOWS.md).
3. Pick a task from the active phase in [docs/ROADMAP.md](docs/ROADMAP.md).
4. Branch from `dev/ui-modernization` as `feature/NN-<name>`. Use Conventional Commits.
5. Before you open a PR:
   - Build with no new warnings in the files you touched.
   - Run the [manual checklist](docs/TESTING.md).
   - Update the phase file and `MEMORY.md`.

Contributions are licensed under BSD 3-Clause ([LICENSE.txt](LICENSE.txt)). Only submit code you understand and can maintain.
Do not submit code, icons or assets copied from proprietary software.

Changes meant for Tahoma2D itself go to [tahoma2d/tahoma2d](https://github.com/tahoma2d/tahoma2d), under its own contribution and AI policies.
